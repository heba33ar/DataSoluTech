# Database schema

**Database:** `healthcare_db` — **Collection:** `patients`

The collection is created with a `$jsonSchema` validator (see
`create_patients_collection()` in `healthcare.py`). Validation is performed by the
MongoDB server, not by the script: any document that does not match the types or
allowed values below is rejected at insertion.

## Fields

| Field | BSON type | Constraints | Example |
|---|---|---|---|
| `_id` | objectId | generated by MongoDB | `ObjectId("...")` |
| `Name` | string | **required** | `Bobby Jackson` |
| `Age` | int | 0 to 120 | `30` |
| `Gender` | string | `Male`, `Female` | `Male` |
| `Blood Type` | string | `A+` `A-` `B+` `B-` `AB+` `AB-` `O+` `O-` | `B-` |
| `Medical Condition` | string | — | `Cancer` |
| `Date of Admission` | date | — | `2024-01-31T00:00:00Z` |
| `Doctor` | string | — | `Matthew Smith` |
| `Hospital` | string | — | `Sons and Miller` |
| `Insurance Provider` | string | — | `Blue Cross` |
| `Billing Amount` | double | — | `18856.28` |
| `Room Number` | int | — | `328` |
| `Admission Type` | string | — | `Urgent` |
| `Discharge Date` | date | — | `2024-02-02T00:00:00Z` |
| `Medication` | string | — | `Paracetamol` |
| `Test Results` | string | `Normal`, `Abnormal`, `Inconclusive` | `Normal` |

`Name` is the only field declared `required`, so a document without a name is
rejected. The other fields may be absent, but when present their type and allowed
values are enforced.

## Data source

The repository contains no CSV file. The dataset is downloaded at runtime from Kaggle
(`prasad22/healthcare-dataset`, version 2) by `dataset.py`.

## Transformations applied before insertion

1. **Deduplication** — `drop_duplicates()` in `dataset.py` removes the 534 strictly
   identical rows present in the published file.
2. **Date conversion** — `Date of Admission` and `Discharge Date` go from the string
   `YYYY-MM-DD` to a `datetime`, because the validator declares them as
   `bsonType: date`. Without this conversion MongoDB rejects the documents.
3. **Name normalisation** — `Name` is stripped and title-cased, so `Bobby JacksOn`
   becomes `Bobby Jackson`.
